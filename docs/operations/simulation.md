# Simulation Strategy

Initial development and validation use simulated infrastructure.

The simulator architecture will eventually provide:

- Spacecraft state
- Telemetry generation
- Subsystem behavior
- Communication behavior
- Ground-station behavior
- Nominal operations
- Failure scenarios
- Thermal anomalies
- Power anomalies
- Sensor failures
- Communication degradation
- Command acknowledgement
- Mission scenarios

Simulation must support deterministic and reproducible scenarios.

Live spacecraft connections are not required during initial development.
